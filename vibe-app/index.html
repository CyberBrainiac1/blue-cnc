        Before you start

        How to use GRBL Prep

        Cutting a flat part

        Pick a part from a Part Studio in this document, pick the material and the end mill, and click Make toolpath. GRBL Prep works out the plate's thickness, the outline, the holes and any pockets from the model, and makes the G-code itself. You don't need CAM Studio.

        It cuts in this order: pockets, then holes and cutouts, then the outline. Every cut ramps or spirals down into the material, so the bit never plunges straight in. The outline leaves small tabs holding the part to the stock. Break or saw through them after the job and file the spots smooth.

        Zero X0 Y0 on the front left corner of the stock and Z0 on its top. The stock needs to be at least the size shown under the preview, and screwed or taped down outside the outline.

        What it can't do

        It only cuts from the top. Pockets on the other side, holes going into the edge, chamfers and rounded edges get listed and left for you. Holes smaller than the bit are listed too, so drill those by hand. Parts with curved or sloped surfaces need a 3D toolpath, so use Kiri:Moto (free in the Onshape App Store) for those.

        More settings

        The suggested numbers are gentle on purpose, for a light router with a 1200 mm/min top speed. If a cut sounds rough, lower the depth per pass first. Feeds and spindle speeds above the machine's limits get pulled back down.

        Already have G-code?

        Use the "I already have G-code" tab. Post your toolpath from CAM as plain G-code and drop the file in. The page changes the parts GRBL can't run, lists every change, and draws the path so you can check it before anything moves. Nothing leaves your computer.

        It takes out program numbers, line numbers, tool length offsets and codes GRBL doesn't have. It turns drilling cycles into plain moves, swaps G28 for a lift and a move back to X0 Y0, and fixes dwells written in milliseconds. If a file uses cutter compensation, feed per rev, macros or a fourth axis, it stops and tells you what to change in your CAM.

        Check the warnings. The most important one is when the job is bigger than the machine's travel.

        Tool changes

        GRBL can't change tools by itself. The converted file stops the spindle, lifts Z and pauses at each change. This page can't jog, so for jobs with more than one end mill it's easiest to click "Download one file per tool", run the first file, swap the end mill and re-zero Z in gSender, then run the next one.

        Which CAM settings to use

        Onshape CAM Studio: pick the 3-Axis Generic Milling - GRBL machine. Fusion 360: the grbl post. Kiri:Moto: the Any.Generic.Grbl device. SolidWorks CAM: the mach_iii post. In all of them, turn cutter compensation off and set feeds in mm per minute.

        Sending

        Plug the GRBL board into the laptop with USB and click Connect. This works in Chrome and Edge. The board resets when it connects, so connect before you turn on the spindle's VFD. Home the machine, zero it on the CAM origin in gSender (close gSender before you connect here), then click Start job.

        Pause holds the motion and Resume carries on. STOP holds the motion and then resets GRBL, so everything stops and the machine needs homing again. If GRBL reports an error, the job pauses and the page says which line and why.

        Inside Onshape

        Click Sign in to Onshape once. GRBL Prep then lists the Part Studios and parts in this document. On the G-code tab it also lists NC files you imported (post from CAM Studio, save the NC file, then use the + menu and Import). "Save to this Onshape document" adds the GRBL file as a new tab, so it's versioned with the part. The page only reads parts and adds file tabs. It never changes your parts.

        Machine settings

        They start out as the team's blue desktop CNC. Change them to match your router. They're saved in this browser.
